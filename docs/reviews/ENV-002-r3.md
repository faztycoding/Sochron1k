## Checked, nothing found (and how)

**(b) Contract fidelity**, by reading `envcheck.py` against each rule, plus the CLI run and probes A–E:
- **Guard order.** `_darwin_guard` (:1262–1268) runs before any process or mount reader (:1371–1389). With a reason set, neither reader is called and the library is never opened; both lines read `unreadable (<reason>)`, and `process_names`, `remote_drives` and `connected_resources` stay None.
- **Pid list.** `proc_listallpids` gets bytes (`sizeof(c_int * capacity)`) and returns a count. `count < capacity` ends the loop; an equal count doubles the buffer; `count <= 0` gives `listed 0 pids`.
- **Process paths.**
  - pid 0 is skipped with no call, and ESRCH (3) is skipped; both are counted.
  - Any other errno gives `errno <n> on pid <pid>, <n> pids`.
  - The own-pid and own-path checks use `os.path.realpath(sys.executable)`.
  - `proc_pidpath` returns 0 on failure, the code checks `<= 0`, and the 4096-byte buffer equals `PROC_PIDPATHINFO_MAXSIZE` (no EOVERFLOW).
- **Mount list.** `getfsstat(buf, sizeof(buf), MNT_NOWAIT=2)` returns a count, and the buffer grows the same way. `MNT_LOCAL=0x1000` and `ESRCH=3` are int constants.
- **struct statfs.** The 2168-byte layout and its offsets are pinned by a unit test, and the real run decoded types, mount points and `map auto_home` correctly.
- **Processes.** The Wine loader rule and the strict `metatrader` component rule match :290–298, and the counting matches r4 F53.
- **Mount rules.** FAIL comes before UNKNOWN, with `continue`, so a FAIL mount never appears in `not allowed:`. The allow list: `/System/Volumes` itself is not allowed, `Data/home` is allowed, anything else under `Data/` is not. `autofs` passes only from `map auto_home`. A missing `/` gives `missing`, and `/` apfs without MNT_LOCAL is FAIL with no `root:` part. The stacked root mount is the one gap (F16).
- **Application folders.** A missing folder is skipped; an unlistable one makes the search incomplete; only names are read, and any entry whose name holds `metatrader` counts.
