## Conventions fixed where the contract leaves room (also in the test docstring)

1. `<repo>` = `Path(__file__).resolve().parents[3]`. The task prompt's hint `parents[2]` points at `tests/` for a file at `tests/acceptance/ENV-001/<file>`.
2. `Item.status` and `Report.verdict` compare equal to "PASS"/"FAIL"/"UNKNOWN" (str or str-valued enum); `Item.detail` is a str; `Report.items` is a tuple with exactly one Item per table row, named as in the contract; order not checked.
3. Facts/Rule/Profile: exact field names, order free (tests use keywords); annotations must evaluate with `typing.get_type_hints`, and Optional/Union/typing.Tuple spellings count as equal.
4. ALLOWED_UDP: ports asserted, names taken from the module (not asserted, so a Server 2022/2025 rename needs no new test). EXPECTED_UV: any non-empty str. Wrong versions are derived from the constants (last number + 1, or major.minor only).
5. os: the caption must start with "Windows Server 2022" or "Windows Server 2025" and the build must be 20348/26100. A client caption with build 26100 FAILs (Windows 11 24H2 shares build 26100, and ProductName there reads "Windows 10 Pro").
6. firewall: "enabled" other than "True" (including "NotConfigured" and "1") and an action other than Block/NotConfigured (including "4") FAIL.
7. inbound: the detail names every failing rule, and render shows the Name too. Advice is asserted only where the contract is unambiguous (see the test docstring item 7).
8. 3389 scope: host bits under a prefix count as that prefix (`strict=False`); 0 entries FAIL like 5; every range FAILs.
9. Address hiding: the AC-06 IPv4 pattern must not match any detail or the render (so masks and 0.0.0.0 are not printed either), and "2001:db8"/"2001:0db8" must not appear. The AC-06 IPv6 pattern is not applied, because it also matches clock times.
10. Last line = `render(report).rstrip("\n").splitlines()[-1]`.
11. "Only inside collect_facts" = lexically inside the top-level `collect_facts` (nested functions included). Literal `importlib.import_module`/`__import__` count as imports. stdlib only.
12. `secret_like_files_in_repo == 0` in the valid Facts stands for a repo whose only env-like file is `.env.example`.
